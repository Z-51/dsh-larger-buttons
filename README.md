# 让 DeepSeek Harness 中的按钮更大、更容易点击，并支持为每种按钮单独设置样式和交互行为。

# 功能

- **扩大点击区域**：分别调整实际可点击的区域和可见按钮尺寸，也可以设置间距、圆角及图标居中。
- **能给不同的按钮单独设置**：复制、分支、点赞、文件打开等按钮可以使用不同外观，也可以让部分按钮保持原样。
- **插件内配置面板**：在本插件详情中也完成调整。提供**预览**、**撤销修改**和**恢复默认**。参数由你的dsh来保存，重启了也会保留。

# 安装

1. 从本仓库的 **Releases** 页面下载 `dsh-external-dsh-branch-hitarea-0.4.3.tgz`，右键它，复制文件路径。

2. 打开 DeepSeek Harness 的 **插件 → 添加插件**。

3. 在文本框中粘贴**文件路径**。

4. 去掉**文件路径**首尾附带的**双引号**。

5. 点击**安装**。
